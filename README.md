## ✦ Overview

Ameen Studio is an independent digital creative studio delivering high-craft Framer development, motion design, and interactive web experiences. 

This repository contains both:
1. **Next.js Production Application**: Modern Next.js 15 App Router + React 19 + TypeScript + Tailwind CSS with GSAP motion and Lenis smooth scrolling.
2. **Standalone HTML Edition (`index.html`)**: Complete, zero-dependency, self-contained single-file edition ready to preview or deploy anywhere.

## ✦ Getting Started

### Prerequisites

- Node.js 18.18+ or 20+ installed
- npm, pnpm, or yarn

### Installation

```bash
git clone https://github.com/IsaacWeb01/ameen-studio.git
cd ameen-studio
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site in your browser.

### Production Build

```bash
npm run build
npm run start
```

### Standalone HTML Preview

Double-click `index.html` or open it directly in any modern browser to view the standalone edition with no build steps required.
